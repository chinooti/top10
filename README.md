# Top 10 Calculator
This is a quick python script I made to congregate top 15 lists into a top 10. 

## About the Project

It's quite common to make top 10 lists in the Valorant Community around global events to gauge community opinion on the best players. This program is designed to assist that.

## Usage

This program is designed to use a Google Form csv as input in a file called "top10.csv". The Google form should have 15 questions labelled "#1" to "#15" to represent the rankings of the individual. Afterwards, the form can be exported as a csv to run with the program.
